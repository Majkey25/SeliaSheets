# SeliaSheets roadmap

Status: Product direction. Updated September 5, 2026. This file is not a release checklist.

Released behavior is documented in [`README.md`](../../../README.md) and [`CHANGELOG.md`](../../../CHANGELOG.md). Dated files under `docs/superpowers` preserve design and implementation history; they are not release claims.

## Current beta

SeliaSheets ships fixed-size paper pages and imported PDF-backed pages with direct page text, vector ink, positioned text, images, shapes, math, chapters, search, OCR, PDF export, and editable backups.

## Planned, not shipped

- FLOW pages with Quick Note and Inbox.
- Rich-text styles, checklists, tables, and graphs.
- Persistent element grouping and reference links.
- Masking tape, flashcards, study history, and audio.

## Stable-release gates

- Green API 29 and API 37 runtime suites on the exact release commit.
- Compatible active-stylus hardware acceptance for pressure, tilt, hover, eraser, and barrel buttons.
- Signed artifact verification, GitHub release verification, and Google Play closed-track acceptance.
