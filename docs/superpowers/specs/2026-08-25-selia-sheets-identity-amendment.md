# SeliaSheets identity amendment

Effective August 25, 2026, the public product and repository name is **SeliaSheets**.

The Android application ID remains `com.majkeylab.seliadocs`. The Room database name, Kotlin package, backup schema identifiers, and legacy signing environment variable also remain stable. These identifiers preserve local data and backup compatibility. They are not user-facing product names.

New editable backup files use the `.seliasheets` extension. The importer continues to accept ZIP-compatible backups created under the previous filename.

Earlier design documents use the historical SeliaDocs working name. This amendment overrides only their public-name and repository-name fields. Their product, editor, storage, and safety decisions remain active.
