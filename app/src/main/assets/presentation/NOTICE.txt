PowerPoint presentation renderer

SeliaSheets includes a locally modified standalone browser bundle from
@aiden0z/pptx-renderer 1.3.0. No Microsoft Office code or fonts are included.

Local changes (2026-09-26): report missing/unsupported charts, chart
initialization failures, and previously swallowed template/group errors through
the supplied onNodeError callback. Dispose chart instances when initialization
fails. This prevents importing failed chart placeholders as successful slides.
Read single-level multiLvlStrCache category labels using their declared count
and sparse point indexes. Reject multiple category hierarchy levels explicitly
because this renderer has no matching hierarchical axis layout.
Exact patch: docs/third-party/pptx-renderer-1.3.0.patch in the SeliaSheets source.
Only Apache-2.0 renderer code changed; the bundled MPL-2.0 mtx-decompressor
component and all other third-party components remain unchanged.
