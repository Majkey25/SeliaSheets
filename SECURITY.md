# Security Policy

## Supported versions

Security fixes are provided for the latest published beta or stable release.

## Reporting

Report a potential vulnerability privately to [majkeylab@gmail.com](mailto:majkeylab@gmail.com). Include the affected version, Android version, reproduction steps, and impact. Do not attach private notebooks, images, signing material, or credentials.

Please allow reasonable time for validation and a coordinated fix before public disclosure.
