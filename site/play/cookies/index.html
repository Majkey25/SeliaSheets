The SeliaSheets policy site is a static GitHub Pages site. Its code does not set cookies or use browser storage, analytics scripts, advertising pixels, fingerprinting, or embedded third-party widgets.

What loads when you visit

Pages load local HTML, CSS, and the project icon from the same site. Fonts use your device's installed fonts. There are no contact forms, embedded videos, social widgets, remote fonts, or payment embeds.

Hosting and external links

GitHub serves this site and processes technical request information, including IP addresses, to operate and secure its services. See the GitHub privacy statement. A website can have server logs without setting a browser cookie. Following a link to GitHub or Google opens a separate service with its own cookie and privacy practices.

Cookie choices

There is no optional tracking technology in this site's code to accept or reject, so the site does not show a consent banner. If optional tracking or embeds are added, this policy and any required prior consent controls must be updated before they load. Your browser also provides controls for cookies stored by other sites.

The Android app

The app does not embed this website in a WebView. Its local settings and notebooks are not browser cookies. Google ML Kit's diagnostic metadata and optional model downloads are separate from website cookies and are described in the privacy policy.
