Privacy

Effective August 24, 2026

Péřko is an offline-first Android notebook published by Majkey25.

Data collection and sharing

Péřko does not collect, transmit, sell, or share personal data. It contains no analytics, advertising SDK, crash-reporting SDK, account system, telemetry, or app network permission.

Data stored on the device

Notebook titles, pages, settings, ink input, text, shapes, arithmetic blocks, and copies of images explicitly selected through Android Photo Picker are stored only in private Android app storage. Android backup is disabled.

User-directed exports and links

PDF export writes only to a destination selected through Android's system document picker. Legal, source, and optional support links open in the user's browser after an explicit tap; the destination website's policy then applies.

Retention and deletion

Data remains on the device until the user permanently deletes it or uninstalls the app. Permanent notebook deletion removes its database content and private image assets that are no longer referenced.

Security

Péřko uses private app storage, validates imported image types and sizes, and does not request broad storage access. Users should protect device access and export sensitive notebooks only to trusted locations.

Children

Péřko is a general productivity tool and is not directed to children under 13. It does not knowingly collect data from any user.

Changes and contact

Material changes will be published here with a new effective date. Contact majkeylab@gmail.com or use GitHub Issues.
